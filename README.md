# ✊ Rock Paper Scissors 🎮

My second Python project.

A simple Rock Paper Scissors game made with Python.

## 🎮 Choices

* 🪨 Rock
* 📄 Paper
* ✂️ Scissors

The computer randomly chooses one option, and the player chooses one too. The program then checks the result and shows whether you **won, lost, or drew**.

Built while learning Python basics. 🐍
